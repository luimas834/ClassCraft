# components

Parts used on more than one screen:

- `ui/` — the building blocks: buttons, inputs, dialogs, tables, badges, and the loading, empty and
  error states every screen needs
- `layout/` — the frame around a page: the menu on the left, the bar on top, and the plain frame the
  public routine uses
- `grid/` — the routine grid itself: the days, the cells, the cards, and the panel of lessons that
  have no place yet
- `timeoff/` — the grid on which days and periods are marked as not available
